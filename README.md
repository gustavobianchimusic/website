# Gustavo Bianchi

Official website for pianist and educator Dr. Gustavo Bianchi.

## Development

```sh
npm install
npm run dev
```

The local development site is available at `http://localhost:4321`.

## Production build

```sh
npm run build
```

The static site is generated in `dist/`. Pushes to `main` deploy automatically
to GitHub Pages through the workflow in `.github/workflows/deploy.yml`.

Production domain: `https://gustavobianchi.com`
